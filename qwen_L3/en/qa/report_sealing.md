# 英文 QA 封板终审报告：v1-hardened（v1 prompt + 加固管道）

> 决策：**英文 QA 线正式封板为「v1 prompt + 加固合成管道」（= v1-hardened）。** 本报告是
> 终审版，汇总全部证据链：prompt 迭代收口、人工审核、n=500 扩样验证、源文档门禁 negative、
> 问题深度/类型画像。所有数字均为真实运行的冻结判官输出（`qwen3.6-35b-a3b`，temp 0），
> 无估算。`config.yaml`、`src/common.py`、`src/synthesize.py`、所有 prompt、中文/rewrite
> 线均未改动。

## 0. 结论摘要

- **生产基线 = v1-hardened**：v1 prompt（`src/prompts/qa_gen_en_v1.txt`，sha256
  `85e5df2a5d02…`）+ 加固同源管道（`scripts/synth_qa_same_source_en.py` → `src/qa_gate_en.py`）。
- **合成模型 = `qwen3.6-27b`**（阿里云 MaaS）；判官 = `qwen3.6-35b-a3b`，temp 0。
- **权威指标（n=500 冻结判官复算）：**
  - 贴合度 closeness **3.698**，95%CI [3.648, 3.748]（半宽 ±0.050）
  - 可解析 **500/500**、幻觉风险 **5.0**、忠实度 **4.992**（3 条 <5，占 0.6%）
  - 覆盖度 **3.922**、可答性 **4.996**、自足性 **4.940**
- **护栏全线守住**（faith ≥ 4.9、hallu ≥ 4.95、可解析 = 100%）。
- **closeness 与问题深度的天花板都是 27B 模型，不是 prompt。** 五次独立实验一致印证。
  再提升唯一杠杆是换更强合成模型——属另开实验，不在本封板范围。

## 1. 为何封板：prompt 迭代已收口（证据链）

| 步骤 | Prompt | 管道 | closeness | 可解析 | faith/hallu | 判决 |
|---|---|---|---|---|---|---|
| v1 基线 | v1 | 原始 | 3.707 | 99/100 | 5.0/5.0 | 通过，> 中文 3.18 |
| v2 软优化 | v2 | 原始 | 3.57 | — | — | 回退，保留 v1 |
| **v1-hardened** | **v1** | **加固** | **3.760**(n=100) | **100/100** | **5.0/5.0** | **采纳（本封板）** |
| v3 focus-pass | v3 | 加固 | 3.677 | 99/100 | 4.97/5.0 | 回退，归档 |

v3 三方对比隔离出两个效应（详见 `reports/en_qa_v3_eval.md`）：

- **管道加固 = 工程胜出（采纳）。** 修了确定性 bug：`common._looks_zh` 的 `[一-鿿]`
  区间把含日文"お粥"的英文文档误判为中文、吐 CJK 标记 `问题：/答案：` 致判官
  `no_question_marker`（row100，v1/v2 都栽）。en 层改用 `src/qa_gate_en.py` 强制
  `Question:/Answer:`（**修复在此，不碰 common.py**）+ `validate_roundtrip` 格式门禁 +
  内容级重试。效果：同源合成 99→**100/100**、closeness 3.707→**3.760**、护栏满分。
- **v3 prompt focus-pass = 回退（归档）。** 对正确基线 3.760，v3 跌 3.677、omits 49→62、
  faith 5.0→4.97（3 行破线，v1-hardened 为 0）。

**这是第三次独立印证**：忠实饱和后 closeness 天花板是 27B 分析深度,非 prompt 覆盖/多样性杠杆。

## 2. 人工审核 — 经冻结数据逐条核验（两轮，全部属实）

**第一轮（v1-hardened vs v3，n=100）：** 用户标注的六分档、faith<5 行、better/same/worse
等全部定量断言经冻结判官复算**逐条吻合**；且所有风险/硬失败均只在 v3、v1-hardened 无一
破线，独立佐证 v1-hardened 为更稳基线。

**第二轮（v1-hardened 分层抽样，n=500 中抽 60）：** 用户标注（avg closeness 3.383、
closeness 分档 1/15/15/18/11、faith<5 行 1/2/3、noise 行 1/32/33/34）经复算**全部属实**。
口径澄清：3.383 是**刻意 worst-first 分层抽样**的样例均值，非全线水平（全线 n=500 为 3.698）。

## 3. n=500 扩样验证：封板经更硬置信度确认

在原 100 上分两批追加 disjoint 官方对齐集（ext100 seed816、ext300 seed917，重叠全 0），
同一封板管道合成、同款判官评测，合并 n=500（详见 `reports/en_qa_v1_hardened_eval_n500.md`）：

- closeness **3.698**，95%CI 半宽从 n=100 的 ±0.105 收窄到 **±0.050**。
- 三批 3.76 / 3.69 / 3.68 均在采样噪声内，**无系统性回退**。
- 可解析 500/500、幻觉 5.0 全程守住。
- **诚实记录的长尾**：ext300 暴露 3 条 faith<5（占 0.6%），逐条查证**全部是噪声源文档**
  （搜索词噪声、语法词沙拉、纯参考文献列表），hallu 仍 5.0——是"没优雅拒绝垃圾输入"，
  非编造。归为生产 QC 抽检监控项。

## 4. 源文档噪声门禁探索：NEGATIVE，不上线（守 L1 红线）

为兜住上述 0.6% 长尾，标定了"合成前源文档连贯性门禁"（详见
`reports/en_qa_source_coherence_gate_negative.md`）：

- **纯启发式/统计预筛证伪**：三种失效模式正交，能抓全的停用词阈值要 flag 367/500（砍 73% 产量）。
- **轻量 LLM 门禁标定（n=500）**：拓全 **3/3** 优于启发式，但 flag 66/500、误杀 63 条，
  误杀主体是参考文献列表/图书馆元数据/碎片等"忠实但低质"源（faith=5 但源本身不配做 QA）。
- **判定不上线**：区分"忠实但低质"= L1/L2 数据质量过滤职责，AGENTS.md 明确不复现 L1/L2。
  若需清洗噪声源应在上游 L1（项目范围外）解决，不在 L3 QA 合成里补。

## 5. 质量画像：问题深度与类型（3163 题实证）

对全 500 文档生成的 3163 条问题做类型/深度分布（实证，非印象）：

| 层次 | 占比 | 代表类型 |
|---|---|---|
| 事实回忆型 | **44.8%** | What 28.2% / Which 11.9% / Who·When·Where 4.7% |
| 推理·机制型 | **21.1%** | Why 10.5% / How 9.2% / Compare 1.2% / Explain 0.3% |
| 客观题·其他 | 34.1% | MCQ·TF 27.2% |

- **做得好**：题量稳（6.33 题/文，落在官方 6–8 区间）；类型多样（What/MCQ/Why/How/Compare
  均有覆盖），含 27% 官方风格的客观题。
- **固有短板 = 深度**：事实型 : 推理型 ≈ 2 : 1，最深的 Compare（1.2%）/Explain（0.3%）
  几乎缺席。这与 closeness 短板同根——官方那版更偏推理/对比，本版更偏事实抽取。
- **关键**：深度偏浅**不是 prompt 能修的**——en v2/v3 两次想用 prompt 拉深度/多样性均回退。
  让 27B 生成真正的对比/推理题需要它有那个分析深度，硬逼只会产教材腔。**深度天花板即 27B 本身。**

## 6. 封板的产物与不变量

- **Prompt**：`src/prompts/qa_gen_en_v1.txt`（sha256 `85e5df2a5d02…`），未改。
- **合成路径**：`scripts/synth_qa_same_source_en.py`（经 `src/qa_gate_en.py`：强制

- **判官**：`scripts/eval_l1_pairwise_qa_en.py`（支持 `--version`/`--records`/`--official`）。
- **冻结产物**（`data/eval/en/`，`git add -f` 入库）：原 100 + ext100 + ext300 的对齐集、
  合成记录、判官输出；门禁标定 `source_coherence_gate_calibration.jsonl`。
- **不变量守住**：输出 schema `{uid, content, style}`；QA content = 原文 + 问答对（原文在前）；
  忠实优先于 closeness；不编造事实；prompt 一律新建版本、不原地改。

## 8. 若未来要再推 closeness / 深度（本封板范围外）

不是 prompt 问题。唯一杠杆是**换比 `qwen3.6-27b` 更强的合成模型**（更大 dense 或带显式
推理链的模型，以获得驱动"官方焦点覆盖 + 深推理题"的分析深度）。注意前提：v3.25 三模型
n=50 对比中 35b 并未赢过 27b，故"换大一档"不保证有效——须换**真正更强**的模型。任何尝试
必须走封板加固管道 + 同款判官，且不得破护栏（faith ≥ 4.9、hallu ≥ 4.95、可解析 = 100%），
评测标准应同时看 closeness **与**问题深度分布（推理型占比）。
