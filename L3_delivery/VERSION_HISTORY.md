## 一、中文 QA（封板 v3.30）

演进主线：v3.25 → v3.28 → v3.29(弃) → **v3.30(封板)** → v3.31(不采纳)

| 版本 | 核心改动 | closeness | 结论 |
|---|---|---|---|
| v3.25 | 早期基线（多轮锚点/题型/源文类型约束累积） | 2.63（35b 判官） | 一度作生产版；78% 纯事实抽取、题型单调 |
| v3.26 | 题型硬配额（单点题≤40%、必覆盖主旨） | 3.05（↓，35b） | ❌ too_textbook_like 16→62 暴涨，教材化回归 |
| v3.27 | 克制放开多样性（不用硬配额） | 3.12（≈，35b） | 治好教材化但 closeness 纹丝不动 |
| **v3.28** | 软约束 + 元引用过滤（前封板） | 2.80（35b）/ 2.49（DMX） | 首个不回归提升，答案 24→27 字 |
| v3.29 | 把规则按 First/Then/Finally 分步骨架重组（内容没变，只改结构） | 2.60（↓） | ❌ 分步骨架诱导教材化，弃用 |
| **v3.30** | **强制题型**（判断+选择+原因硬要求，忠实优先级>题型配额）+ L0 加固 | **2.76（DMX）** | ✅ **封板**（2026-08-07 拍板） |
| v3.31 | 去"判断题:"标签 + 判断题后置疑问 + 选择题思辨引导 | 2.72（DMX，↓噪声内） | ⏸️ 不采纳：指令全执行但不涨分 |

**v3.30 相对 v3.28（DMX 同判官同种子 99 篇配对）**：closeness 2.49→2.76（**+0.27**）、题型多样 +0.96、
答案质量 +0.41；faithfulness 名义 −0.12 经逐条核查为判官把强制题型风格偏离计入、真编造≈0（非质量回退）。

**核心结论（三重证明）**：closeness 瓶颈是 27b 分析深度（模型天花板），非 prompt。v3.26/v3.27 放开展开度→
教材化回归；v3.31 去标签+改句式→指令全执行仍不涨分；同 prompt 下 opus-4-8 合成 closeness 3.0 vs 27b 2.76。
**prompt 已到边际，要再动 closeness 只能换更强合成模型。**

**数据卫生（L0 + 种子层，均在 code 内）**：
- `common.py`：删露怯元话语答案、修复选项错位到答案字段、多选答案保护。
- `synthesize.py`：`_ocr_garble_reason` 拦截整篇中文 OCR 断裂垃圾源文（500 条种子池命中 1 条零误伤）。
- CLEAN 生产产出四类脏数据（露怯/选项错位/`<think>`/OCR 垃圾源文）全部归零。

**吞吐**：c16 实测墙钟 85.7 篇/min（0 think，success 0.985）。

## 五、跨线共性结论（第一性）

1. **两类线的北极星不同**：QA 用 official_closeness（"像官方"），rewrite 用 refinement_value（"精炼价值"）。
   rewrite 的优化目标（去噪/忠实/连贯）直接对齐训练价值，故一次封板即稳；QA 的 closeness 只是结构一致性
   代理，易钻牛角尖。项目真目标是 better learnability（退火训练数据），closeness 非目标本身。
2. **QA 两线的 closeness 瓶颈都是模型天花板**：prompt 形式改动（骨架、标签、句式）动不了；只有
   任务内容改动（强制题型、去坏数据）有效，且已到边际。要再进一步需换更强合成模型。
3. **忠实红线始终优先于风格/接近度**：L0 只删坏数据不补造；强制题型忠实优先级高于题型配额。
